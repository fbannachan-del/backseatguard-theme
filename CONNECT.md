# Connect BackSeatGuard theme to this repo

## One-time (you)

1. Open Shopify admin for BackSeatGuard.
2. **Online Store → Themes**.
3. Click **…** on your current theme → look for **Connect to GitHub** / **Edit code** isn’t enough — you need GitHub connect.
4. If you only see “Edit code”, use: **Add theme → Connect from GitHub** (wording varies by Shopify version).
5. Pick repo **fbannachan-del/backseatguard-theme**, branch **main**.
6. Tell Grok: “Shopify is connected / theme is in the repo”.

## Then

- Reply in chat with this folder open as context: `/Users/frankie/backseatguard-theme`
- Or: “pull the theme” and run CLI pull into this directory
- Design phase starts: colours, header, hero, product page, spacing
