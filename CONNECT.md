# Connect Shopify to this repo

Repo is now a **valid Dawn-based theme** (not empty docs).

1. Shopify → Online Store → Themes
2. Add theme → Connect from GitHub  
   OR … menu → Connect theme library to GitHub
3. Select **fbannachan-del/backseatguard-theme**, branch **main**
4. Should succeed

If error remains: hard refresh Shopify, wait 30s after push, try again.
